# AnimeRift

AnimeRift is a Java-only Android application source tree designed for low-end Android devices, Android 6.0+ compatibility, and Android 11 / 32-bit ARM support. The project intentionally avoids Gradle, Maven, Kotlin, Compose, and generated build files.

## Current implemented features
- Java-only Android app structure under `com.animrift.app`
- Home catalog screen with search and genre filtering
- Local favorites and viewing history using SQLite + SharedPreferences
- Native media playback using Android `VideoView`
- Local file selection through the Storage Access Framework
- Direct URL validation before attempting remote playback
- Arabic-first strings with English fallback
- Manual library documentation in `LIBRARIES.txt`

## Not yet implemented
- Production remote API integration with a real authorized anime source
- Advanced subtitle rendering beyond basic local file support
- Download manager UI for direct media downloads
- Better poster art and richer catalog metadata
- Full device/emulator validation in this environment

## Source tree
- `app/src/main/java/com/animrift/app/` — application package root
- `app/src/main/res/` — XML layouts, styles, drawables, and values resources
- `app/src/main/AndroidManifest.xml` — app manifest
- `docs/` — build and feature notes
- `LICENSE` — repository license

## Manual setup
1. Open the project in an Android Java-compatible IDE.
2. Import the `app/src/main` tree as the Android app source root.
3. Add the Android SDK platform and Java support packages required for Android 6.0+.
4. Install any extra libraries manually only if the app is extended beyond the current framework-first implementation.
5. Build with the Android SDK directly; do not generate Gradle files.

## Build limitations
- This repository is not a Gradle project and intentionally does not contain Gradle or Maven configuration.
- The project should be built using an Android SDK workflow in a compatible IDE.
- No claim of successful APK compilation is made unless a local Android SDK build is performed and verified on-device or in an emulator.
