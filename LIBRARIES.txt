AnimeRift project structure

Root files
- README.md — project overview, current features, limitations, and manual setup.
- LIBRARIES.txt — all relevant third-party dependencies documented manually.
- LICENSE — repository license.
- PROJECT_STRUCTURE.txt — actual tree and module summary.
- docs/ — documentation and status notes.

Application module
- app/
  - src/
    - main/
      - AndroidManifest.xml — app manifest and permissions
      - java/com/animrift/app/
        - MainActivity.java — home catalog activity
        - model/Anime.java — anime metadata model
        - network/SourceValidator.java — HTTP/HTTPS validation helper
        - player/VideoPlayerActivity.java — local/direct video playback screen
        - repository/AnimeDataSource.java — metadata source contract
        - repository/AnimeRepository.java — in-memory catalog repository
        - storage/FavoritesHistoryStore.java — SQLite + SharedPreferences for favorites/history
        - ui/AnimeAdapter.java — anime list adapter
        - utils/UrlUtils.java — URL helper utilities
      - res/
        - layout/ — activity_main.xml, activity_video_player.xml, item_anime.xml
        - drawable/ — icon and card resources
        - mipmap-anydpi-v26/ — adaptive launcher icons
        - values/ — colors.xml, strings.xml, arrays.xml, styles.xml
        - values-ar/ — Arabic strings resource

Notes
- This project intentionally uses Android framework APIs first and avoids unnecessary third-party dependencies.
- No Gradle or Maven build configuration is present.
- The structure remains deliberately compact and suitable for low-end Android devices.
